# IOP · 仪器接入

[English](instrument-setup.md) · [Agent 接入](agent-setup.zh-CN.md) · [驱动](drivers.md) · [软件计算](software.md)

一个可操作的仪器说明包含：设备标识、连接方式、驱动、操作名称、参数与单位、返回数据、完成条件。Runtime 保存说明并执行操作；人、Agent 和实验程序使用同一套定义。

## 从连接到可用操作

1. 发现接口。串口、VISA 和软件程序显示在可配置接口中，USB 清单单独显示。Windows 串口与指向它的 VISA 地址归为一组；原始接口仍可通过 API 读取。
2. 选择设备使用的驱动。串口说明通信通道；它本身不说明设备使用 SCPI、Modbus 或厂商二进制命令。已有仪器说明可以直接导入；SCPI 使用仪器手册规定的波特率和结束符。
3. 保存说明。ID 自动生成，可以修改。保存后的说明可导出、共享并再次导入；重复提交同一说明复用已有设备。
4. 执行已定义的操作。SCPI 的“读取身份”发送 `*IDN?`，将制造商、型号、序列号与固件版本显示在操作旁。其他操作按其定义展示参数和返回值。保存配置与读取仪器响应分别留有明确状态。
5. 扩充型号能力。使用驱动原有操作，或在说明中加入手册支持的命令、参数范围、物理单位和完成条件。SDK 设备通过独立驱动进程接入；Java、C、C++、C#、Python 等实现共用同一进程接口。

## 一次配置，多次使用

Agent 从 `lab_context` 读取已有设备与平台，从 `describe_instrument` 读取完整操作。多设备接入可调用 `register_instruments`；每项分别返回设备或错误。设备 ID、扫描协调和执行记录由 Runtime 处理。实际接线、样品位置以及研究目标无法从接口推断时，再由已有实验资料或人补充。

平台说明保存连接关系、共享对象、资源数量与初始化过程。单台仪器可以直接调用；跨仪器工作流用 `after` 表达先后关系，用 `bindings` 传递前一步结果。对独立设备的调用可以并行，访问同设备或同资源的调用按配置排队。

## 连续实验与数据

已知步骤批量提交。依赖观测反馈的循环放在实验程序中，通过 Python、TypeScript 或 HTTP 调用。运行编号、参数、操作结果与文件统一保留；关闭界面或 Agent 后实验继续执行。

SCPI 文本响应使用缓冲读取，支持跨数据包的结束符与后续数据保留。串口参数可配置 `baudrate`、`bytesize`、`parity`、`stopbits`、`xonxoff`、`rtscts`、`dsrdtr`。图像、波形等大数据使用驱动文件输出与流式文件接口，SDK 的专用二进制采集由对应驱动实现。

查看状态时只读取摘要；需要数据时再读取结果、分页操作或文件。设备动作的完成条件、硬件触发和采样速率由仪器及驱动定义，Runtime 负责它们之间的依赖与资源安排。
